What actually turns on

Four shader layers for Roblox. Toggle them in the popup. Dial one back if a map is already heavy.

  1. Bloom Lights spill instead of clipping.
  2. Haze Distance goes soft. Worlds get air.
  3. Weight Corners darken. Things sit on the ground.
  4. Focus The edges of the frame fall off, like a lens.

Two minutes. Developer mode.

  1. 1

    Download, then extract

    Save rbxmods.zip. Right-click → Extract All. You should see manifest.json in that folder. Do not drag the .zip into Chrome.

  2. 2

    Load unpacked

    chrome://extensions → Developer mode on → Load unpacked → pick the extracted folder (the one with manifest.json). Never pick the .zip.

  3. 3

    Enable Shaders

    Pin rbxmods, launch Roblox, hit the toolbar button, and tap Enable Shaders.

Before you install

What is this?

rbxmods is a shader pack for Roblox — realistic shadows, dynamic lighting, bloom, haze, depth, and color grading that makes every world feel alive.

Chrome, Edge, Firefox?

Yes. Install rbxmods once, then play Roblox with shaders on. Brave and Opera GX use the same Load unpacked path.

“Could not unzip extension”?

Extract rbxmods.zip first, then Load unpacked on the folder that contains manifest.json — not the archive itself.

Ban risk?

rbxmods is unofficial and not made by Roblox. Read their rules yourself before you install.

FPS?

Shaders use your GPU. If a world is already heavy, drop Bloom or Focus in the popup.

Mac?

rbxmods shaders run on Roblox across Windows, macOS, and Linux.
