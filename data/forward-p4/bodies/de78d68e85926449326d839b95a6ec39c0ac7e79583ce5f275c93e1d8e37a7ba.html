Circuit Ledger — Dark Developer Portfolio (Next.js & React)

🌐 Live Website: https://circuit-ledger.vercel.app

Circuit Ledger is a modern, high-performance developer portfolio built with Next.js 14, React 18, and TypeScript in a “Quiet Circuitry” design language.

It combines a hacker-terminal aesthetic with clean editorial design:

  • ⚡ Interactive Canvas Background: Real-time 2D canvas animation with dynamic circuit runners, binary bit field, and mouse tracking.
  • 🎨 Modern Dark Aesthetics: Void dark theme with champagne cream (#F7E2C0), circuit green (#4ADE80), and neon accents.
  • 📱 Fully Responsive Layout: Accessible bento grid, scroll-spy navigation, interactive mobile menu, and smooth scrolling.
  • 💻 Interactive Live Terminal: Typewriter animated code preview showcasing modern tech stack proficiency.
  • 🛠️ Performance & SEO Optimized: Built using Next.js App Router, SSR pre-rendering, and semantic HTML5.

🛠️ Tech Stack

  • Framework: Next.js 14 (App Router)
  • UI & Logic: React 18 & TypeScript
  • Styling: Modern Modular Vanilla CSS (globals.css)
  • Icons: Custom SVG vector graphics
  • Deployment: Vercel

🚀 Getting Started

Prerequisites

Make sure you have Node.js 18+ installed on your system.

Installation

  1. Clone the repository: 
    git clone https://github.com/your-username/circuit-ledger.git
cd circuit-ledger
  2. Install dependencies: 
    npm install
  3. Run the development server: 
    npm run dev
  4. Open http://localhost:3000 in your browser to view the portfolio.

📦 Building for Production

To create an optimized production build:

npm run build
npm run start

🌐 Live Demo & Deployment

The application is deployed live on Vercel: 👉 Project URL: https://circuit-ledger.vercel.app

☁️ Deploying to Vercel

Option 1: Deploy via Vercel CLI (Recommended)

  1. Install Vercel CLI globally: 
    npm i -g vercel
  2. Run the deployment command in the project root: 
    vercel --prod

Option 2: Deploy via Vercel Dashboard (GitHub Integration)

  1. Push your code to a GitHub repository.
  2. Go to Vercel Dashboard.
  3. Import your GitHub repository.
  4. Framework Preset will be automatically detected as Next.js.
  5. Click Deploy.
